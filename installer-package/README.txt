Resume Builder Installer
========================

How to install on a Windows computer:

1. Unzip this folder.
2. Double-click Install-ResumeBuilder.bat.
3. Windows may show a warning because this is a local unsigned installer. Choose "More info" and "Run anyway" if needed.
4. The installer creates a desktop shortcut named "Resume Builder".

Where it installs:

%LOCALAPPDATA%\ResumeBuilder

Notes:

- No admin permissions are required.
- The app runs in the user's normal web browser.
- Resume data autosaves in that browser on that computer.
- The Backup button downloads a JSON backup that can be kept or moved to another computer.
